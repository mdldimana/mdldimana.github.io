# Portfolio — Merlin Dimana · MdlSoft

Site portfolio statique (HTML/CSS, sans dépendance).

## Mettre en ligne avec GitHub Pages
1. Déposer tous ces fichiers à la racine du dépôt.
2. Sur GitHub : **Settings → Pages → Source : Deploy from a branch → main / (root)**.
3. Le site est en ligne quelques minutes plus tard sur `https://<pseudo>.github.io/<dépôt>/`.
